# Installation

```bash
git clone https://github.com/T0rMax/arc.git
cd arc
npm install
npm run dev
```

---

# PWA Installation

## iPhone

1. Open ARC in Safari
2. Tap Share
3. Select “Add to Home Screen”
4. Launch ARC like a native app

## Android

1. Open ARC in Chrome
2. Tap “Install App”
3. Launch from home screen
